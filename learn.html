Most engineering education stops at the equation. Most coding tutorials never touch real engineering. Almost nobody shows you how to actually use AI on real work without handing you an answer you can't check. This library does all three — the physics, the implementation, and the workflow — and every tool on this site is a worked example of it.

Why this exists

I went looking for the geotechnical engineering community online. The Discords are empty. The subreddits are quiet. The forums are archives of conversations that ended a decade ago. For a discipline that decides whether buildings stand up, there is almost nothing being taught in the open.

Meanwhile the good material sits behind $2,000 review courses, and the code that engineers quietly write to do their jobs — the spreadsheets, the scripts, the little solvers — never gets shared at all. Every one of us rebuilds the same tools alone.

So this is the thing I wanted and couldn't find. It's free because a discipline with no public teaching doesn't need another paywall — it needs somebody to start. I'm studying for the PE Geotechnical exam myself, so I'm studying in public: you get the material as I build it, mistakes named and corrected where I make them.

The format

Every lesson answers three questions

This is the part that doesn't exist anywhere else. Not the theory alone, not the code alone — the whole path from soil behavior to a running tool.

1 · How does it work?

The actual mechanics, drawn. Effective stress, seepage, bearing capacity — explained the way it behaves in the ground, with figures you can read at a glance.

2 · How do I code it?

Working, readable code that computes it — and the numerical traps that make it wrong. Copy it, run it, check it against a hand calculation.

3 · How do I use AI here?

The real workflow: what to hand off, how to prompt it, and — most importantly — how to verify the answer as an engineer before it reaches a drawing.
