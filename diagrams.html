How this library is maintained

Free, and corrected in public

Every figure here is free to look at and free to learn from. I'm building the set while studying for the PE Geotechnical exam, so I'm not going to pretend it's infallible — what I can promise is how it gets handled when something is wrong.

Generated from code

Figures are produced by scripts, not drawn by hand. The geometry is explicit, so it can be checked — and an error is a one-line fix and a re-run, not a new edition.

Solved where it matters

The seepage flow net is a numerical solution of Laplace's equation, not a sketch. Where a figure can be computed instead of approximated, it is.

Errors get fixed and named

When I find a mistake — in my own work or in a source — I correct it and say what it was. A reference nobody ever corrects isn't careful, it's just quiet.

Reviewed by an engineer

Every figure gets checked by someone who knows what it's supposed to say, whatever tool produced it. That review is the part that makes a drawing trustworthy.
